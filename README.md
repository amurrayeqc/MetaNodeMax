# MetaNodeMax

MetaNodeMax enables real-time, distributed data processing through an auto-scaling and load-balancing framework, optimizing node performance and efficiency.

MetaNodeMax is built to be simple and practical, focusing on doing one thing well.

**Why MetaNodeMax?**

- MetaNodeMax enables real-time, distributed data
- processing through an auto-scaling and
- load-balancing framework, optimizing node performance

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/MetaNodeMax.git`
2. `cd MetaNodeMax`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
